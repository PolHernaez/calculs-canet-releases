# Càlculs Canet — descàrregues

App per repartir les despeses d'un grup (qui ha pagat què, quant toca a cadascú i qui paga a qui).

**Descarregar l'última versió:** [Calculs-Canet.apk](https://github.com/PolHernaez/calculs-canet-releases/releases/latest/download/Calculs-Canet.apk)

Un cop instal·lada, l'app avisa sola quan hi ha versió nova (Ajustos → «Buscar actualitzacions»).
Aquest repositori només conté les versions publicades; el codi és privat.
